Lagos Ascent: an original canvas game. Pilot a kite over Lagos lagoon, thread golden rings, dodge yellow danfo buses, grab fuel, and clear 3 levels.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: WASD / arrow keys / mouse, SPACE to start, P to pause.
